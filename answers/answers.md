## 评分口径与集成

- 主分数是 **Base Score（基础分，0.0–10.0）**，不是业务风险等级或验证成功概率；取消旧的 `severity` 文字等级字段。
- 保留数组及 `id`、`locations`、`type`；新增描述、影响、前提、`cvss` 和 `assessment`。集成读取 `cvss.base_score`、`cvss.base_vector`；`cvss.vector` 是显式包含全部 **22 项**指标的完整向量。
- 基础指标为 AV、AC、PR、UI、S、C、I、A 共 8 项；时序为 E、RL、RC 共 3 项；环境为 CR、IR、AR、MAV、MAC、MPR、MUI、MS、MC、MI、MA 共 11 项。
- 未独立评估的时序及环境指标逐项保留 `X`（Not Defined）。`X` 不等于不存在、不受影响或已验证。E/RL/RC 与 CR/IR/AR 的默认系数均为 1；其余修正指标继承基础值。
- `temporal_score`、`environmental_score` 是按 X 默认值计算的派生数值，**不是已完成威胁情报或实际部署评估的独立结论**；对应 `*_assessed=false`。
- `metrics` 保留原始取值，`effective_metrics` 记录继承基础值后的实际取值，`metric_weights` 记录数值权重。S/MS 选择计算公式，没有普通乘数，权重为 `null`。`sub_scores` 保留 ISS、Impact、Exploitability 及三个环境分项。
- 最终分数由 FIRST 官方计算器实现计算，并用 Red Hat Product Security 的 `cvss==3.6` 独立复算。按规范 Roundup 向上保留 1 位小数，不用普通四舍五入；正文分项仅为显示截取，最终分数不由截取后的分项回算。

统一假设：

- 按独立漏洞和源码所声明的角色校验评分，不将其他编号漏洞串联，也不利用公开教学账号口令绕过角色前提；普通会员记 PR:L，后台运营/管理员记 PR:H。
- HTTP 入口的基础 AV 按 N 评分；默认仅绑定 127.0.0.1 是部署限制，不将网络漏洞改记为本地漏洞。
- 应用、专用业务数据库、运行目录及专供该应用的辅助服务作为同一安全范围；不推定容器逃逸、宿主入侵或外部系统失陷。浏览器脚本跨越服务端到受害者浏览器的边界时记 S:C。
- 仅静态分析，未运行 POC、攻击请求或漏洞验证；利用成熟度、修复状态、外部报告可信度以及部署环境均未独立评估，保留对应指标 X。

默认教学口令保留时的实际攻击门槛可能更低，部署方应另行评估 MPR；基础评分不把公开口令与每个原题串成同一漏洞链。竞争条件在 v3.1 计入 AC:H，v3.1 不含 v4.0 的 AT 指标。

SQL 注入按当前查询路径评分：本版本设置 `PDO::ATTR_EMULATE_PREPARES=false`，`PDO::query()` 会先调用驱动 preparer，普通 SELECT 走原生 `mysql_stmt_prepare`。字符串拼接依然允许改变查询结构，但不能只凭默认多语句连接标志或账号权限推定堆叠写入、任意删表已经成立。因此 01/23 按敏感数据读取，28 按报表完整性及其回显可见性评分。依据见 [PHP PDO::query 实现](https://raw.githubusercontent.com/php/php-src/php-8.4.27/ext/pdo/pdo_dbh.c)与 [PHP 8.4.27 MySQL 驱动](https://raw.githubusercontent.com/php/php-src/php-8.4.27/ext/pdo_mysql/mysql_driver.c)。若建立额外写入、结果返回或可用性影响路径，应复评。
