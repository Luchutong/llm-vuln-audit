# PHP 输出编码与 XSS

检查顺序：

1. 确定输出上下文：HTML 文本、属性、URL、JavaScript、CSS、JSON。
2. 追踪数据从存储或请求到输出的完整路径，确认持久化后被读取时是否再次解码。
3. 核对编码函数是否匹配上下文；`htmlspecialchars` 不能保护未加引号的属性或脚本块。
4. 检查模板引擎的自动转义是否被关闭、被 `raw`/`safe` 标记绕过，或只对部分变量生效。
5. 浏览器证据必须来自实际执行；单纯出现可疑输出不等于脚本已执行。

常见误判：

- 输出经过 `strip_tags` 仍可在允许的标签或属性中注入事件处理器。
- 反射型参数需要用户交互，报告应写清触发条件与受影响身份。
- 存储型数据在写入时转义、读取时又反转义，最终仍在页面中成为标记。

知识提示只说明检查方法，不能替代当前源码行号证据。
