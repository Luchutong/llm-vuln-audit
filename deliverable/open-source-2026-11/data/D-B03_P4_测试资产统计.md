## 3. 与 2026-11-07 采集的差异（同一套用例，两次结果一致）

| 项目 | 11-07 | 11-08（本表） | 结论 |
| --- | ---: | ---: | --- |
| 后端用例数 | 2,268 | 2,268 | 一致，用例集未变动 |
| 后端通过 / 失败 | 2,265 / 3 | 2,265 / 3 | 一致，失败项完全相同 |
| 后端耗时 | 137.7 s | 273.42 s | **几乎翻倍** |
| 前端用例数 | 125 | 125 | 一致 |
| 前端通过 | 125 | 125 | 一致 |

耗时差异近 2 倍，原因是本次运行时虚拟机同时承载后端服务、Playwright 浏览器与实验进程，CPU 竞争激烈。**结论：通过率与用例数可作证据，耗时不可作性能指标引用**。若报告需给耗时，须注明"负载条件下采集"。

