## 4. 复核方式

```bash
# 方式一：本表口径（Python 脚本，无需额外依赖）
python scripts/gen_p3_loc.py

# 方式二：cloc 原版（需自行安装 cloc；数值会低于本表，因 cloc 去空行去注释）
cloc backend frontend/src labs/lab30 poc_runner --exclude-dir=node_modules,.venv

# 方式三：单目录快速核对
find backend -name "*.py" | xargs wc -l | tail -1
```
