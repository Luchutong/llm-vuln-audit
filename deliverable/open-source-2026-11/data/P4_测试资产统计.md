## 3. 采集命令

```bash
# 后端（需 dev 与 poc 两个 extra，缺一会导致 pytest 或 POC 用例缺失）
cd backend
uv sync --project . --frozen --extra dev --extra poc-claude

# 前端
cd frontend
npm test          # node --test tests/*.test.mjs
```
