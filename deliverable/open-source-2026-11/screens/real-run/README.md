两次终态都是 `inconclusive`，后端记录的原因是：

> 源码挖掘阶段额度已到，未完成方向保留。（第一轮：请求预算 64 用尽）
> 源码规划回合已到预留边界，保留最终验证复核机会。（第二轮：Planner 16 回合用尽）

这不是失败，也不是程序异常：`inconclusive` 是平台对「预算耗尽但已有可交付结论」的正式终态。
两轮都达到 **源码覆盖率 100%**，并各自产出可下载的阶段报告。报告里必须照实写，
不能写成「已完成」「全部验证通过」——**终审接受分别是 6 条和 7 条，不是全部候选**。
