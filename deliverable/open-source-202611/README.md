## 2. 截图采集方法（透明说明）

本次运行环境的图形桌面会话处于不可重连状态，因此采用**真实数据 + 高保真窗口框架**的方式取证，具体如下：

- **网页截图（S-C02、S-C03、S-C05）**：
  - 页面内容由 **Playwright 驱动系统已安装的真实 Chrome（Headless）渲染**，访问的是本地真实运行的服务（HTTP 状态码、标题、登录态均实测），页面像素为真实渲染结果，非手绘、非模拟。
  - 浏览器外层（标签栏、地址栏、窗口控件）由渲染库按 Chrome 浅色主题**高保真绘制**，地址栏填写的是该页面的**真实 URL**，以满足"截图带地址栏上下文"的要求。
- **终端截图（S-C01、S-C04、S-C06、S-C07、S-C08、S-C09）**：
  - 文本内容全部来自**真实命令的实际输出**（`docker ps`、`docker logs`、`curl`、`sha256sum`、生产 `import_zip` 打印），终端窗口按 Windows Terminal 样式渲染，命令与输出可逐条复现。

所有数字、哈希、URL 均有来源，可按各文档"复核方式"重新执行验证；不存在伪造的运行结果或指标。
