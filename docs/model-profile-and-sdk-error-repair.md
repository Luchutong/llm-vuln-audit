# 模型档案生效与 SDK 异常诊断修复

日期：2026-10-30。参考复测：`ad3697d442ba5fd5887bc8472f9cb991`。

## 档案为何没有生效

配置页选中的档案持久化在 SQLite，服务启动后会恢复选中项；`.env` 负责环境档案的启动配置。原实现没有把浏览器保存的档案导出到 `.env` 的操作。

已创建任务冻结了 `model_profile`。此前继续任务直接复制原运行，因此切换全局选中项仍不影响新复测中的 Planner／终审；这条复测沿用了原来的 `ark-code-latest`，终审遇到账号周配额耗尽。POC SDK 则采用独立的 `deepseek-flash` 上游，两者不能混作同一个连接。

现在：

- 新建继续任务默认使用配置页当前选中的档案，弹窗显示其名称及模型。可显式选择另一档案或沿用原任务档案。
- `POST /api/runs/{id}/continuation` 增加 `model_profile_id`；`current` 为默认，`original` 明确继承，其余值为档案 ID。新任务冻结选择；历史任务和冻结报告不变。
- 配置页增加“同步当前档案至 .env”，调用 `POST /api/config/sync-env`。只有用户点击才导出 `LLM_MODEL`、`LLM_BASE_URL`、`LLM_API_KEY`、`LLM_THINKING`，保留其他行及 POC 独立配置。
- 导出用同目录临时文件原子替换，文件权限为 0600。失败保留原文件，接口不返回密钥。有排队、运行或暂停任务时拒绝导出。
- 进程外显式环境变量仍优先于 `.env`；导出文件不会改变既有任务的冻结模型，也不会热更新 POC 网关。

## SDK 异常为何被显示成未触发

两项实验留下 `usage.execute_reason=sdk_api_error`，之后只读结论阶段成功返回了 `inconclusive`。原记录器只看最后的 `reason=completed`，加上已有成功 HTTP 作业，便保存为 `not_triggered`，丢失了“实验中断”的语义。

现在：

- SDK 实验阶段异常与结论发布结果分别保留。即使结论发布成功，只要实验因 SDK／运行时异常中断且最终仍未决，就记录 `execution_error`。
- 已有成功作业仍可以交给预留的只读结论阶段使用；有合法对照证据才能形成确定结论。不重放副作用，不把普通页面访问或退出码 0 当成攻击成功。
- SDK `api_error_status`、已知错误类别，以及网关 HTTP／连接／超时／SSE 错误元数据写入诊断事件和验证用量 JSON；能力撤销后仍能保留诊断。
- 仅持久化白名单元数据，不记录错误正文、消息正文、提示词或凭据。旧记录没有保存的具体 HTTP 错误仍显示未知。
- 前端识别旧记录中的 `execute_reason`，不改写数据库或历史报告；新记录的详情及报告展示新的执行状态和诊断。

## ark-code-latest 停用

根据用户确认，该模型已失效。当前选中档案 `ds4.1 / deepseek-flash` 已显式同步至实际 `.env`；未改变 POC 独立上游或其他配置。

新建审计、继续任务、档案选择、配置检测及模型调用入口拒绝 `ark-code-latest`。历史任务和冻结报告保留原模型名称；即使选择“沿用原档案”，也不能再次调用这个已停用模型。其他模型仍按任务冻结档案执行，不自动切换供应商。

本轮定向后端 73 项、前端 107 项、模拟浏览器 36 项均通过，构建通过。当前服务选中模型已核对为 `deepseek-flash`；新增后端禁用校验需下次启动加载。

下述未导出真实 `.env` 的验收边界指上一轮 SDK 修复。本轮用户明确停用旧模型后进行了上述同步，没有启动模型请求或新审计。

自动验证使用模拟 SDK、模拟上游、临时 `.env` 和数据库；浏览器拦截全部 API。未通过本次修复启动真实模型、POC 或靶场重置。

- 后端定向回归 231 项通过；追加协议错误诊断后，相关网关／适配器 52 项回归通过（与前者有重叠，不累加计数）。
- 前端 `npm test` 107 项通过，`npm run build` 通过；构建仍有原有的大包体积提示。
- 模拟浏览器 36 项通过，包含 StrictMode、档案选择、显式导出、错误恢复及 1440／1024／768／390px 布局。
- 后端进程没有重启，新接口和 SDK 处理需要下次重启后加载；没有自动执行 `.env` 导出或创建真实继续任务。

验收期间曾有新增测试误启动应用 lifespan，刷新环境档案的显示元数据；已从测试前的冻结快照恢复。新测试不进入 lifespan，环境变量恢复使用独立映射，并额外将测试数据目录限制为 `/tmp`。原审计记录、`.env`、凭据和选中档案没有被替换。
